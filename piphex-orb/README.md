# Piphex Orb

A focused native companion app for iPhone. It opens directly to Piphex's orb—no website, menus, or storefront.

## Run on an iPhone for development

1. Install **Expo Go** from the App Store.
2. In this folder, run `npm start`.
3. Scan the QR code with the iPhone camera.
4. Allow microphone access when asked.

The app calls the secure public Piphex backend. No OpenAI or ElevenLabs API key is stored in the app.

## Interaction

- Tap once to start listening.
- Tap again to send the recording.
- Tap while Piphex is speaking to interrupt him.
- Use the small keyboard button for text chat and recent local conversation history.
